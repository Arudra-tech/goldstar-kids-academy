# Goldstar Kids Academy — Website

A single-page marketing website for Goldstar Kids Academy, a daycare in Monmouth County (Freehold), NJ.

## Features
- Sticky "Schedule a Tour" CTA header
- Hero with direct tour CTA
- Center info bar (hours, phone, 5.0★ Google rating)
- "Now Welcoming New Families" availability badges
- Programs grid (Infant → School Age + Summer Camp)
- Founder spotlight (split photo + bio panel)
- Real Google reviews
- 2-step in-person tour booking widget (parent info → interactive calendar + time slots)
- Footer with contact info

## Tech
Plain HTML/CSS/JavaScript in a single self-contained file. No build step, no dependencies.

## Running locally
Open `index.html` in any web browser. That's it.

```
open index.html
```

## Editing
All markup, styles, and scripts live in `index.html`. Edit and refresh the browser.
